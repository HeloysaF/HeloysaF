## Projetos

### Portal do Cidadão
Plataforma que aproxima os cidadãos das decisões tomadas pela câmara de vereadores de suas cidades. As leis são apresentadas em linguagem simples, acessível a qualquer pessoa alfabetizada, e a população pode registrar sua opinião sobre cada uma. Os vereadores, por sua vez, publicam as leis e acompanham a opinião dos cidadãos.

O projeto está em desenvolvimento, com back-end em Java e integração com banco de dados. Já conta com documentação, levantamento de requisitos e diagramas.

**Tecnologias:** Java, banco de dados
